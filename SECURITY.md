# Security policy

## Supported versions

Before 1.0, only the latest published minor line receives security fixes. After 1.0, the
current major line and any explicitly documented long-term-support line are supported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use
[GitHub's private vulnerability reporting](https://github.com/JoviDeCroock/preact-a11y/security/advisories/new)
and include:

- the affected version or commit;
- the accessibility, integrity, or confidentiality impact;
- a minimal reproduction or attack path; and
- any known mitigations.

Maintainers will acknowledge a report within seven days, coordinate remediation and release
timing with the reporter, and publish an advisory after a fix is available. Please avoid
public disclosure until that coordination is complete.
